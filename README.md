# 숨소리 · 한 주 알레르기 전망

비영리 공개 시험판. `dist/index.html` 하나로 작동하는 buildless HTML/JS 사이트.

- 목적: 서울·경기 사용자가 지역 선택 후 7일 꽃가루 노출 전망을 확인할 수 있는지 검증.
- 줄이는 위험: 공식 관측으로 오인되는 예측, 제공기간 밖 대기자료 조작, 실외 습도의 실내 농도 대체.
- 지표: 지역 선택·전망 조회·날짜 상세·공유·도움 응답. 브라우저 내 횟수만 기록. 운영자용 집계는 없음.
- 데이터: Open-Meteo 7일 기상예보, CAMS PM2.5 최대 5일. 꽃가루는 계절+기상 자체 참고 규칙. 기상청 공식 API 미연결.
- 실내: 사용자 입력 유지 가정. 검사 날짜·장소·기관 표시. 건강 데이터 서버 전송 없음.
- 공개본은 개인 증상·처방약 기능을 담은 기존 Vault HTML과 별도 파일로 관리.
- 검증: `node test.cjs`. 실응답 검사 `node test.cjs --live`.
- 운영: 방문 때 갱신, 지역별 30분 브라우저 캐시. 실패 시 같은 날짜 캐시, 이후 계절 경향만 표시. 일자별 값 누락은 숨기지 않음.
- 한계: 임상적으로 검증되지 않음. 꽃가루 실측/공식 예보 아님. 무료 날씨 API는 비상업용 평가로 제한. 상업화 전 계약 필요.
- 다음 실험: 5명이 도움 없이 지역과 주의 날짜를 찾는지 관찰. 3명 이상 재방문 여부를 동의 기반으로 확인. 이번 공개만으로 고객·지불 가설 통과를 선언하지 않음.
